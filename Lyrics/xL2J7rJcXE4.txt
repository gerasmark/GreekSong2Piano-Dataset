Λίγο πριν φύγεις 
δείξε μου κάποιον 
να υπάρχει στον κόσμο 
να πάω να τον βρω.
Δείξε μου κάποιον
που σαν εσένα 
να κλέβει το βλέμμα
όταν μέσα του κοιτώ.

Βρες μου έναν άλλο 
που να είναι σαν εσένα
να 'χει χέρια ανοιγμένα 
όταν πέφτω να πιαστώ. 
Βρες μου έναν άλλο
που το σώμα να θυμάται
κάποιον που να μη φοβάται
όταν λέει σ' αγαπώ. 

Δείξε μου κάποιον
που να σου μοιάζει
μα δεν υπάρχει
δε γεννιούνται εκατό. 

Βρες μου έναν άλλο 
που να είναι σαν εσένα
να 'χει χέρια ανοιγμένα 
όταν πέφτω να πιαστώ. 
Βρες μου έναν άλλο
που το σώμα να θυμάται
κάποιον που να μη φοβάται
όταν λέει σ' αγαπώ.
